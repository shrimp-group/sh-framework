- **分层结构**：模块内部按职责划分为 `base`（基础模型与响应 `R`）、`exception`（以 `CommonException` 为根的分层异常）、`user`（基于 `ThreadLocal` 的 `UserContext`）、`annotation`（元数据注解）及 `spi`（扩展接口）。
- **依赖方向**：核心包 `com.wkclz.core` 不依赖上层业务，仅依赖工具包 `sh-tool` 和 Lombok；`base` 包中的 `BaseEntity` 等类引用了 `annotation` 和 `exception`，体现了基础模型对元数据和错误处理的依赖。
- **关键边界**：通过 `ResultCode` 枚举统一定义全局状态码，`R<T>` 提供标准化的 API 响应构造方法；`UserNameProvider` 接口定义了 SPI 扩展点，允许外部模块注入用户名解析逻辑。
