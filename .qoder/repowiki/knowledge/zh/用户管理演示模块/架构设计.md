- **分层架构**：采用经典的 Controller-Service-Mapper 三层结构。`UserRest` 负责 HTTP 请求处理与 VO/Entity 转换；`UserService` 继承框架 `BaseService` 提供通用业务逻辑；`UserMapper` 继承 `BaseMapper` 实现数据访问。
- **路由管理**：通过 `Route` 接口集中定义 API 路径常量，并使用自定义 `@Router` 和 `@ApiDesc` 注解进行元数据管理，实现路由与描述的解耦。
- **框架集成**：入口类 `DemoApplication` 启用 Spring Boot 自动配置并扫描 Mapper 接口。依赖内部封装的 `sh-web`（Web 增强）和 `sh-mybatis`（MyBatis 增强）模块，复用基础 CRUD 能力。
- **数据模型**：严格区分持久化对象（`entity.User`）与视图对象（`vo.user.*`），在 Controller 层通过 `BeanUtils` 进行手动属性拷贝转换。
