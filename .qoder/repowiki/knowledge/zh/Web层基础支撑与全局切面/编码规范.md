- 全局异常处理器中针对不同类型的异常（如 SQL 错误、参数校验失败、业务异常）映射特定的 HTTP 状态码并统一返回 R 对象。
- 使用 ThreadLocal (LocalThreadHelper) 在请求生命周期内传递上下文数据（如请求日志、异常信息），并在过滤器或拦截器中负责清理以防止内存泄漏。
- REST 接口元数据扫描通过反射解析 Controller 类及方法上的 Mapping 注解，并结合自定义 @Router/@Desc 注解补充业务描述。
- 响应体增强逻辑通过递归遍历对象图收集 BaseEntity 实例，并利用 SPI 接口 UserNameProvider 批量查询用户名后回填，避免 N+1 查询问题。
