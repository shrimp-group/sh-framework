- **自动装配入口**：通过 `ShWebAutoConfig` 配合 `META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports` 实现 Spring Boot 自动配置，扫描 `com.wkclz.web` 包。
- **全局切面层 (`rest`)**：包含 `ErrorHandler`（基于 `@RestControllerAdvice` 的统一异常捕获与告警邮件发送）和 `UserNameBodyAdvice`（基于 `ResponseBodyAdvice` 的实体用户名自动填充）。
- **工具辅助层 (`helper`)**：提供 `RestHelper` 用于反射扫描 Controller 接口元数据，`LocalThreadHelper` 封装 ThreadLocal 实现请求链路上下文传递，以及 IP/Request/Response 等常用 Web 操作助手。
- **通用模型层 (`bean`)**：定义分页、ID、增删改查等基础请求/响应对象（如 `PageReq`, `RestInfo`）。
- **校验扩展层 (`annotation`)**：提供自定义 Jakarta Validation 注解 `AtLeastOneNotNull` 及其实现类，支持跨字段联合校验。
