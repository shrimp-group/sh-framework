- **分层聚合架构**：采用 Maven 多模块聚合，`sh-parent` 继承 Spring Boot 4.0 父工程并导入 `sh-bom` 实现全栈依赖版本锁定。
- **自动装配驱动**：各功能子模块（如 `sh-dynamicdb`, `sh-redis`）均通过 `META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports` 声明自动配置类，实现零 XML 的组件化接入。
- **契约隔离设计**：`sh-core` 定义全局响应体 `R`、异常体系及用户上下文，作为跨模块通信的通用契约；`sh-demo` 作为标准范式验证各组件协同逻辑。
