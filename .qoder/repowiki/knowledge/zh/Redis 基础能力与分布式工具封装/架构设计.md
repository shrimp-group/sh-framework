- **自动装配入口**：通过 `ShRedisAutoConfig` 结合 `META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports` 实现 Spring Boot 3.x 风格的自动发现与组件扫描。
- **配置分层**：`RedisConfig` 负责业务参数（如 AutoType 白名单）注入；`RedisTemplateConfig` 定义 `RedisTemplate<String, Object>` 与 `StringRedisTemplate` Bean，集成自定义序列化器；`RedisKeepAliveConfig` 定制 Lettuce 客户端的 Socket 保活与超时策略。
- **核心工具层**：`helper` 包提供 `RedisHelper`（统一 CRUD 封装）、`RedisLock`（基于 Lua 脚本与 Watchdog 机制的分布式锁）、`RedisIdGenerator`（基于时间戳与 Redis 自增的短 ID 生成）。
- **消息队列抽象**：`queue` 包定义 `RedisMessageQueue` 接口及 `RedisMessageQueueImpl` 实现，基于 List 结构提供阻塞/非阻塞消息收发能力。
- **安全序列化**：`serializer` 包实现 `Fastjson2JsonRedisSerializer`，采用 `JSONReader.autoTypeFilter` 白名单机制替代全局 AutoType，防止反序列化漏洞。
